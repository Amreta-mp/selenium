## 🧩 What We're Exploring

This project is built around four Selenium challenges.

Instead of treating web pages as static screens, we explore how Selenium can **identify elements, work with collections, navigate CSS selectors, and interact with nested elements.**

```text
WEB PAGE
   │
   ├── 🔍 Identify elements
   │
   ├── 📋 Handle multiple elements
   │
   ├── 🎯 Use CSS selectors
   │
   └── 🌳 Navigate child elements



```
